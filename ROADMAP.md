# Roadmap

## V2 — deliver and stabilize

Deliver a clean replacement for V1 with less technical debt and an efficient Go
backend.

- Support every task available in V1 while preserving its familiar UI/UX.
- Serve the workspace, boards, and object-based REST API through one local port.
- Start fresh V2 data alongside V1.
- Prioritize implementation, deployment, and production stability.

Keep V2 focused on that delivery. Place frontend framework evaluations,
migrations, and proof-of-concept work in the V3 exploration.

## V3 — explore after V2 is stable in production

Explore a web stack beyond TypeScript alone, including reactive component
frameworks. Evaluate whether they improve maintainability, state management,
and browser update efficiency for localswim.

V3's framework choice remains open.
