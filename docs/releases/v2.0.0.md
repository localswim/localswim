# localswim v2.0.0

Terry accepted V2 as fully functional on 2026-11-14. The Go backend and freshly
written TypeScript frontend restore the V1 workflows and UI/UX on one loopback
service. The frontend was implemented without reusing V1 presentation code.

  Final product commit `123fdf08175fa6a10734843c9ecea64ce1798860` contains the
  accepted tree from `8e64fa99396002bf61f0ddef69f8c5ba54243e4e`.
- The full quality gate passed with 316 browser-client tests and Go checks.
  [Integrated qualification](../planning/0581-t6-handoff.md) and
  [release audit](../planning/0581-t6-release-audit.md) retain the evidence.
- Terry and Bot completed all seven [minimal acceptance tests](../ui-minimal-acceptance.md).

- Terry reported noticeably faster interaction. Performance on 600-card boards
  has not been measured.
