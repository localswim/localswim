F1 - Invalid selector text reaches human terminal output

- core/run.go formats q.selected.BoardID directly into the human outcome line,
  including when parsing rejected that selector. An invalid --board value with
  ESC and newline characters is emitted verbatim and can forge terminal lines.
- Emit only validated canonical selected identity or a fixed inert placeholder
  on invocation errors. Never render rejected selector bytes in diagnostics.
- Independent synthetic invalid-selector control-text probe reproduces this.
  JSON mode remains a single safe envelope in this case.

F2 - UUID selector validation decodes an extra escape layer

  into a valid UUID instead of being rejected as noncanonical selector text.

  mismatch, rather than failing invocation validation before source loading.

  escape sequences. Cover board, incarnation, grant and positional IDs.

  selector case reproduces this defect.
