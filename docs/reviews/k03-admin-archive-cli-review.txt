Reviewed behavior

  explicit selectors and no implicit actor, credential search or owner fallback.
- Exact private credential paths use native protected creation, pins, alias/link
  checks and per-credential exclusion. Ordinary access coexists with the server
  lease and remains independent of owner-bearer expiry. Publication failure cannot
  silently restore ordinary use.
- Self-revoke captures the enabled bearer once, binds its current session, then
  durably marks it disabled before one DELETE. A preexisting marker preserves
  uncertainty without another session GET. Lost results retain the marker.
- Grant and recovery commands share immutable evidence, readback and one domain
  dispatch. Human enrollment and the original recovery preview require their
  exact terminal challenges. Original lookup never resubmits an operation;
  unproven domain outcomes and lookup failures remain unknown.
- Credential/code issue use separate typed native-owner paths and strict response
  binding. Secrets stay in private callbacks/native storage or the private console
  channel. Public SessionCodeCLI contains no secret or private-path field.
- Upload freezes metadata and raw bytes before evidence/network waits. Download
  checks observed immutable digest/length and native flush/readback/no-overwrite
  publication. Its BoardRead JSON is metadata; invocation context and exit status
  communicate local delivery.
- Export freezes one observed revision, sends one request, validates the whole A03
  package and then publishes locally. Offline restore/status delegate unchanged
  A04 behavior, including request-reference delivery before effects. Later output
  loss preserves completed publication and reports delivery uncertainty.
- The exact stored D01 port controls pinned TLS. Default 47443 and explicit 48443
  both passed actual private native integration; different-origin evidence cannot
  query or rebind an original operation.
