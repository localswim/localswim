  G01 rechecks current grant, actor and rights; restart clears browser registries

  exact Host and presented Origin, browser-write/exchange Origin and JSON,
  same-origin Fetch metadata for absent-Origin browser GET, and actual CLI
  verification before the native absent-Origin exception. No native self-revoke.

  transport checks only and must authenticate through guarded G02 methods before
  reads/effects. Bearer shape creates no principal or ordinary native privilege.

  cleanup, no HTTP fallback, current certificate/lifetime guards, bounded request
  handling, no-store replies, no cookie/CORS authority, fixed inert diagnostics,
  same-origin CSP and denied framing. Parent README/adapter decision match scope.
