   export bytes unchanged. Stop all owned hosts and verify listener closure.

Capacity and continuation
Private editable draft recovery retains at most20 live drafts/2MiB per profile
installation across windows/boards. A refused draft save keeps visible input;
read-only search can still work. It does not claim that input is durable.
Submitted immutable operation evidence has a separate100-unresolved/8MiB budget.
A deliberate Save can therefore proceed after draft-cap refusal only if fresh
immutable evidence is strictly committed and read back before dispatch. The draft
warning does not waive that admission. Failure to freeze verified evidence means
unsent; UNKNOWN remains independent and must never be inferred from search.
Avoid filling a shared everyday profile during a demonstration. Use a fresh
synthetic profile, inspect private metadata and clear only deliberately selected
records with the ordinary warnings; clearing private data never changes server
facts or makes an uncertain original safe to retry.
