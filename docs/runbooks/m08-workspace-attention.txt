Workspace Attention

Open the workspace root to choose a board. Each row shows Blocked, Needs Terry
and Ready for Review from one authorized board observation. The same facts appear
in the sidebar and chooser. Read the policy version and explicit or implicit
category source and assigned lane labels below the counts.

A number includes only live cards in that category's assigned lanes. Zero means
the category is configured and contains no live cards. Not configured means no
lanes are assigned. Unavailable means the current observation has no trusted
count. An out of date number belongs to the last trusted observation and its
displayed policy context. Refresh to request current facts.

The list refreshes every five seconds while the window is visible and on focus.
Card movement, archive changes and category edits appear on a later refresh.
Each board is observed independently. Activity remains the first ordering key.
Only an exact activity tie uses the fresh known Attention total.

Use Filter boards to match a project or board label or key. Pin boards and use
the arrow buttons to change saved pin order. Arrow keys, Home and End move
through the visible sidebar links. Enter opens the focused board. Catalog refresh
preserves the active editor, private draft, filter and focus. Each window keeps
its own private input while shared saved facts refresh.

If workspace access is lost, the visible catalog and its Attention context are
removed. An unavailable saved pin keeps its public key reference and an Unpin
action. It does not retain prior counts, lane labels or policy details.

For machine-readable parity, run the actual CLI against the same workspace.

  localswim --workspace WORKSPACE --json workspace catalog
  localswim --workspace WORKSPACE --project PROJECT --board BOARD --json attention show

See m08-attention-catalog.txt for snapshot and ordering rules and
m08-category-configuration.txt for category configuration.
