M11 | Inspect retained activity in the browser

Open an ordinary local browser session and select a board. Choose Activity on
that board. The view shows the board ID and incarnation and the server's recent
seven-day UTC interval, with an exclusive start and inclusive end.

Each row shows the committed time and event type, original board and
incarnation, origin-local event ID and revision, and recorded actor kind and ID
when available. A restored event can have a different origin from the selected
board. An unknown kind means the recorded attribution could not establish
human or automation.

Coverage complete means the recorded coverage spans the interval. A complete
empty result says "No activity in this interval." Coverage gapped means some
evidence in the interval is missing. Coverage expired means the selected
board's floor covers the interval. Gapped and expired pages can still show
retained events. The floor and applicable origin gaps are listed when present.
Activity unavailable means the inspection failed.

Choose Next page to see older events from the same capture when that control
is offered. If the cursor is stale, choose Start fresh to capture a new first
page. The view waits for that action. Start fresh also retries an unavailable
inspection. Closing Activity, switching boards, or reconnecting discards the
open inspection. Open Activity again on the current board as needed. The
board's editor and private drafts use their ordinary lifecycle.

Focused client verification from web/ after installing the locked dependencies
and building with the pinned Node runtime:

  node --test src/api/activity.test.mjs
