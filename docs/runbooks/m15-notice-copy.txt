M15 original local notice Copy

Open Notices on the selected board, then Read inbox. Each retained positive
notice shows its captured original text and Copy original text. Legacy notices
remain inspectable with original text unavailable; their Copy is disabled.
Captured fallback notices are real originals and can be copied.

Copy deliberately performs a fresh ordinary inbox read before writing. The
same target, delivery identity and exact validated payload must still exist.
A missing, changed, legacy, refused or failed fresh response cannot use cached
text. No board edit, receipt acceptance or external delivery is submitted.

Success appears only after navigator.clipboard.writeText resolves. Unsupported
clipboard access, denied writes and expired browser gestures remain visible
failures. A slow fresh read may consume the browser's gesture window; choose
Copy again deliberately. There is no hidden fallback copy mechanism.

The saved original and the writeText argument use canonical LF separators.
Windows represents those separators as CRLF on its native clipboard. No
terminal newline or other content is added. Use notices text when an exact
UTF-8 LF byte stream is required. Qualification compares the native Windows
result to that exact platform representation without trimming or normalizing
the received clipboard data; see M15-LOCAL-TEXT-R3 for the evidence boundary.

Copy preserves drafts and focus. Closing, switching boards/incarnations,
suspending a window or losing authority fences pending reads and success UI,
including A-to-B-to-A navigation. An OS write already invoked cannot be undone
by navigation. No clipboard restoration is promised. A write not settled within
ten seconds is reported unconfirmed; later settlement cannot announce success.

Proof boundaries

- web/src/board/notices.test.ts uses controlled asynchronous component/API and
  clipboard behavior. It is not native OS clipboard or actual gesture proof.
- web/scripts/original-text.test.mjs tests the reusable production helper with
  controlled clipboard outcomes, validation, immutable snapshots and timeout.
- Real-browser/default/configured-board and shared-queue evidence is maintained
  separately by the M15.06 browser qualification operator. Diagnostics must
  exclude captured notice text and other private prose.

Copy supports human forwarding. It does not prove product adapter acceptance,
absence of independent forwarding, no effect, or future delivery permission.
