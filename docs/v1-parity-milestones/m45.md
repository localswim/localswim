## Work

Store search, selected card and lane scroll by board in tab-scoped state. Restore them on board return, Back or Forward and reload. Use stable IDs and clear invalid selections without applying one board's state to another.

## Demo and acceptance

Set different filters and scroll positions on two boards, leave a drawer selected, then switch back and reload with the same view restored.
