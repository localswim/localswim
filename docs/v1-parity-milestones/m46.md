## Work

Keep recent confirmed board data in a per-tab LRU with a configurable byte budget. Paint the retained view immediately and refresh in the background using the normal load path. Show freshness, bound in-flight reads and evict predictably.

## Demo and acceptance

With refresh deliberately delayed, reopen a recent board and use its retained view. Exercise failed refresh and Retry, then lower the cache budget and show eviction.
