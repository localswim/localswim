## Work

Keep pending attachment IDs and file fingerprints per tab, without storing file bytes. Confirm already-committed uploads before any retry. Reselect matching originals after reload and continue known uncommitted uploads against the original card. A missing readback while the original upload may still be running leaves the outcome unknown.

## Demo and acceptance

Drop a response after an upload commits, reload and locate the original attachment ID. Keep an unresolved in-flight upload fenced. Reject a different file with the same name and continue a known uncommitted upload after reselecting the matching original.
